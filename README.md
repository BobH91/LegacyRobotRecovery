# Legacy Robot Recovery

## Purpose

This project is dedicated to recovering, preserving, and documenting a legacy robotics system from an archived Raspberry Pi SD card.

This repository is intentionally kept separate from the NanoBot project.

## Rules

1. No files from this project are to be copied into NanoBot without a deliberate decision.

2. NanoBot development must remain completely independent.

3. Recovered files are historical artifacts and should be preserved in their original form whenever possible.

4. Reports, notes, and documentation belong only in this project.

## Directory Structure

Reports/
Engineering reports and recovery summaries.

Recovered_Files/
Copies of recovered software and data.

SD_Image/
Disk images and mounted image information.

Documents/
Recovered documentation.

Photos/
Pictures of hardware and recovery process.

Notes/
Investigation notes and observations.
